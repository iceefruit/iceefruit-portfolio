# DESIGN.md — Iceefruit Editorial & Engineering Portfolio

## 1. Concept Card (`awwwards` + `top-design`)

```
Idea:        An industrial-grade engineering monograph and live acoustic/3D laboratory for Iceefruit.
Metaphor:    Teenage Engineering hardware manual meets AREA 17 / Locomotive editorial monograph.
Signature:   A 12-column exposed hairline architectural grid where live Web Audio DSP frequencies physically drive a Three.js wireframe core and editorial chapter transitions.
Emotion:     Tactile precision, quiet authority, and mechanical responsiveness within the first 3 seconds.
Motion verb: Snap like a mechanical relay; reveal like a blueprint sheet (`cubic-bezier(0.16, 1, 0.3, 1)`).
Screenshot:  The asymmetric monumental Hero poster intersecting the 3D wireframe core, flanked by the live FFT spectrum readout and the dual Doodle/ASCII portrait frame.
```

## 2. Anti-Slop Quality Contract (`no-ai-design-slop` + `top-design`)

- **BANNED:** Skill percentage bars (`95%`, `90%`). Replaced with an editorial capability index and real architectural proof.
- **BANNED:** Centered hero over a glowing blob with two rounded pill buttons and a 4-card stat row. Replaced with an asymmetric 12-column poster layout with monumental `Space Grotesk` + `Instrument Serif` display type.
- **BANNED:** Generic 3-column rounded icon cards with `bg-surface/80 rounded-xl`. Replaced with exposed hairline index tables, folder tabs with physical blueprint drawers, and full-width magazine case studies.
- **BANNED:** Emojis (`💥`, `⚡`, `✓`) anywhere in the UI. Replaced with custom technical SVG schematics and crisp vector geometry.
- **BANNED:** Chatty AI filler copy. Replaced with specific engineering nouns, real repository architectures (`ONNX RMBG-1.4`, `Faster-Whisper INT8`, `HMAC-SHA256`, `MapLibre GL`, `ZeroMQ`), and honest before/after engineering benchmarks.

## 3. Art Direction & 60-30-10 Palette

| Role | Token | Hex | Usage |
|---|---|---|---|
| **60% Ground** | `icee-dark` / `icee-darker` | `#0A0A0C` / `#060608` | Warm physical obsidian canvas (never pure `#000000`) |
| **30% Structure & Ink** | `icee-text-bright` / `icee-text-muted` / `icee-border` | `#F4F3EF` / `#8E929F` / `#1E2028` | Warm alabaster type, technical slate copy, exposed `1px` structural hairlines |
| **10% Signal Accent** | `icee-orange` / `icee-orange-glow` | `#FF5E00` / `#FF7700` | High-voltage international orange for active relays, audio FFT peaks, folder tabs, and the finale chapter |

## 4. Typography System (`top-design` Pillar 1)

- **Display Sans:** `Space Grotesk` — tight negative tracking (`-0.04em`), monumental scale `clamp(3.75rem, 10vw, 9.5rem)`, line-height `0.92`.
- **Editorial Accent Serif:** `Instrument Serif` (italic) — paired inside display headlines for editorial tension.
- **Technical Mono:** `JetBrains Mono` — used for coordinates, schematics, DSP readouts, file paths, and terminal I/O.
- **Body Copy:** `Plus Jakarta Sans` / `Space Grotesk` — `16px` (`1rem`), generous line-height `1.65`, constrained to `60ch` measure.

## 5. Chapter Sequence (`editorial-portfolio-chapters`)

1. **Chapter 00 // Poster & Identity:** Asymmetric 12-column architectural frame, monumental typography, 3D audio-reactive wireframe core, and dual-avatar portrait switcher (`Dizzy Doodle` + `ASCII Matrix` + Pinterest aesthetic backdrops).
2. **Chapter 01 // Engineering Case Studies (`portfolio-case-study-writer`):** Deep-dive technical monographs on `City-Api`, `Transparent & Transcribe AI Gateway`, and `ExML / GoldAlgo Quant Engine` with custom SVG architecture schematics and Before/After benchmark tables.
3. **Chapter 02 // IceeOS Specimen Archive (Folder System):** Tactile tabbed file-folder cabinet that opens blueprint drawers containing live interactive mini-sandboxes (8-Voice DSP Synth Matrix, 3D Mesh Inspector, Kernel Source).
4. **Chapter 03 // Acoustic Hardware Deck (Dual-Channel Mixer):** Teenage Engineering-styled dual-deck audio workstation with equal-power crossfader, rotary/linear lowpass filters, custom audio dropzone, and real-time orange FFT spectrum analyzer.
5. **Chapter 04 // Live GitHub Repository Index & CLI:** Full-width sortable editorial index table synced with `/api/github/repos`, live repository file/README inspector drawer, classified NDA ledger, and interactive `icee@system` terminal.
6. **Chapter 05 // Capabilities & Signal Finale:** Oversized typographic capability rows and a high-contrast international-orange transmissionplink.
