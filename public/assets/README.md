# Iceefruit Portfolio - Public Assets Dropzone

Place your custom visual assets directly into this directory:

1. **Profile Picture (`pfp.png`)**:
   - Recommended resolution: 512x512 px (1:1 square ratio)
   - Transparent PNG or dark background fits best with the cybernetic glowing frame.

2. **Banner Image (`banner.png`)**:
   - Recommended resolution: 1920x600 px (16:5 or 3:1 ratio)
   - Cyberpunk, dark synthwave, or abstract geometric artwork blends seamlessly with the header glassmorphism.

3. **Favicon / Logo (`icon.png`)**:
   - 32x32 or 64x64 icon.
