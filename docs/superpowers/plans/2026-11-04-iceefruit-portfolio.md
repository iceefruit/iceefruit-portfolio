# Iceefruit Portfolio Website Implementation Plan (Anti-Slop Editorial Stack)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a bespoke, award-caliber personal portfolio website for Iceefruit using the Anti-Slop Portfolio Stack (`top-design` + `editorial-portfolio-chapters` + `portfolio-case-study-writer` + `no-ai-design-slop`), featuring an asymmetric 12-column architectural grid, 3D audio-reactive Three.js core, Teenage Engineering-styled dual-deck DSP sound engine, tactile tabbed IceeOS specimen archive with live mini-sandboxes, deep-dive engineering case studies with custom vector schematics, live GitHub repository vault, and dual-avatar switcher with Pinterest aesthetic gradient backdrops.

**Architecture:** Next.js 15 App Router with TypeScript, Tailwind CSS (60-30-10 palette), native Web Audio API singleton with procedural synthesis, Three.js client canvas with graceful CSS fallback, and Vitest test-driven development.

**Spec:** `docs/superpowers/specs/2026-11-04-iceefruit-portfolio-design.md` & `DESIGN.md`

## Global Anti-Slop Directives & Quality Contract

- **Strict 60-30-10 Palette:**
  - 60% Ground: Deep dark obsidian canvas (`#0A0A0C`, `#0B0C10`).
  - 30% Structure: Monochromatic slate borders (`#1E2028`, `#2A2E39`, `#3E4451`), alabaster text (`#F4F3EF`, `#E2E8F0`), technical slate (`#8E929F`).
  - 10% Accent: International Signal Orange (`#FF5E00`, `#FF7700`) for active relays, audio FFT spectrum peaks, folder tabs, and uplink.
- **Typography as Architecture:**
  - Space Grotesk (tight tracking, monumental scale), Instrument Serif italic accents, JetBrains Mono for coordinates/DSP metrics.
- **No AI Slop:**
  - Zero skill percentage bars. Replaced with editorial capability index and architectural proof.
  - Zero generic 3-column icon cards with rounded corners. Replaced with 12-column exposed hairline grids and blueprint index drawers.
  - Zero emojis in UI. Replaced with custom technical SVG schematics and vector geometry.
  - Zero chatty filler copy or em-dashes. Concrete engineering nouns and verified benchmarks only.
- **Audio & WebGL Safety:**
  - Web Audio stays suspended until user interaction to comply with browser autoplay policies.
  - Three.js catches context loss gracefully with high-tech CSS fallback.
